## Usage

```tsx
import { Label } from "@/components/ui/label"
import { ConfirmSwitch } from "@/components/ui/sureui/confirm-switch"

<ConfirmSwitch id="two-factor" defaultChecked onConfirm={saveTwoFactor} />
<Label htmlFor="two-factor">Two-factor authentication</Label>
```

Turning it off takes a second click. Turning it on happens at once. Both call `onConfirm`, and a returned promise keeps the switch pending.

## API reference

### ConfirmSwitch

Takes every prop of the shadcn `Switch`, like `id`, `name`, `size`, `disabled` and `readOnly`, except `render` and `nativeButton`.

| Prop | Type | Default |
| --- | --- | --- |
| `onConfirm` | `(checked: boolean) => void \| Promise<unknown>` | required |
| `onCancel` | `() => void` | — |
| `checked` | `boolean` | — |
| `defaultChecked` | `boolean` | `false` |
| `onCheckedChange` | `(checked: boolean) => void` | — |
| `confirmWhen` | `"off" \| "on" \| "both"` | `"off"` |
| `gesture` | `"click-again" \| "hold" \| "popover" \| "dialog"` | `"click-again"` |
| `timeout` | `number` | `3000` |
| `cancelOnBlur` | `boolean` | `true` |
| `duration` | `number` | `1200` |
| `confirmOnRelease` | `boolean` | `true` |
| `cancelHoldOnLeave` | `boolean` | `true` |
| `holdFallback` | `"click-again" \| "none"` | `"click-again"` |
| `title` | `string` | — |
| `description` | `ReactNode` | — |
| `confirmLabel` | `string` | `"Turn off"` |
| `cancelLabel` | `string` | `"Cancel"` |
| `variant` | `"default" \| "outline" \| "secondary" \| "ghost" \| "destructive" \| "link"` | `"default"` |
| `announcements` | `{ armed?, hold?, fallback?, ready?, pending? }` | — |

Each gesture takes only its own props. `"popover"` needs `description`, and `"dialog"` needs `title`.

### Data attributes

The switch sets the same `data-state` values as [Confirm Button](/docs/confirm-button#data-attributes), without `undo`.

## Accessibility

- While armed or held, `aria-checked` keeps the saved value.
- Space, or a click on the switch's `Label`, counts as a click on the switch.
- Each state change is announced in a polite live region, like "Click again to turn off". Change the text with `announcements`.
