## Usage

```tsx
import { BulkConfirm } from "@/components/ui/sureui/bulk-confirm"

<BulkConfirm
  count={selected.length}
  label={(count) => `Delete ${count} issues`}
  onConfirm={deleteSelected}
/>
```

Up to 10 items it's a [Confirm Button](/docs/confirm-button#undo) with undo. Up to 100 it needs a [second click](/docs/confirm-button#click-again). Above that it becomes [Type to Confirm](/docs/type-to-confirm), and the phrase is the count, so deleting 248 issues means typing 248. With `count={0}` the button is disabled. Change the count in the example above to see each one.

## Examples

### Thresholds

`thresholds` sets the highest count for undo and for click again. Here one member gets undo, up to 20 need a second click, and more need the count typed.

## API reference

### BulkConfirm

| Prop | Type | Default |
| --- | --- | --- |
| `count` | `number` | required |
| `label` | `(count: number) => ReactNode` | required |
| `onConfirm` | `() => void \| Promise<unknown>` | required |
| `onCancel` | `() => void` | — |
| `onConfirmError` | `(error: unknown) => void` | — |
| `thresholds` | `{ undo?, clickAgain? }` | `{ undo: 10, clickAgain: 100 }` |
| `errorLabel` | `ReactNode` | — |
| `variant` | [`Button`](https://ui.shadcn.com/docs/components/base/button) `variant` | `"default"` |
| `disabled` | `boolean` | `false` |
| `className` | `string` | — |

When `count` crosses a threshold, the control switches and starts over, so a half-finished confirmation never carries across.

## Accessibility

- The label says the count, so screen readers hear "Delete 248 issues", not "Delete".
- Each level has the accessibility of the control it uses: [Confirm Button](/docs/confirm-button#accessibility) for undo and click again, and [Type to Confirm](/docs/type-to-confirm#accessibility) for the typed count.
