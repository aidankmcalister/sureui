## Usage

```tsx
import { Button } from "@/components/ui/button"
import { ConfirmPopover } from "@/components/ui/sureui/confirm-popover"

<ConfirmPopover
  description="Open pull requests from this branch will close."
  confirmLabel="Delete branch"
  variant="destructive"
  onConfirm={deleteBranch}
>
  <Button variant="outline">Delete branch</Button>
</ConfirmPopover>
```

Cancel, Escape, a click outside or tabbing out close it and call `onCancel`.

## API reference

### ConfirmPopover

It has no `undo`, since it closes when the action commits. Use [Undo Toast](/docs/undo-toast) for a way back.

| Prop | Type | Default |
| --- | --- | --- |
| `description` | `ReactNode` | required |
| `children` | `ReactElement` | required |
| `onConfirm` | `() => void \| Promise<unknown>` | required |
| `onCancel` | `() => void` | — |
| `title` | `string` | — |
| `confirmLabel` | `string` | `"Confirm"` |
| `cancelLabel` | `string` | `"Cancel"` |
| `showCancel` | `boolean` | `true` |
| `variant` | [`Button`](https://ui.shadcn.com/docs/components/base/button) `variant` | `"default"` |
| `side` | `"top" \| "bottom" \| "left" \| "right" \| "inline-start" \| "inline-end"` | `"bottom"` |
| `align` | `"start" \| "center" \| "end"` | `"center"` |
| `open` | `boolean` | — |
| `onOpenChange` | `(open: boolean) => void` | — |
| `gesture` | `"click" \| "click-again" \| "hold"` | `"click"` |
| `timeout` | `number` | `3000` |
| `cancelOnBlur` | `boolean` | `true` |
| `duration` | `number` | `1200` |
| `confirmOnRelease` | `boolean` | `false` |
| `cancelHoldOnLeave` | `boolean` | `true` |
| `holdFallback` | `"click-again" \| "none"` | `"click-again"` |
| `announcements` | `{ armed?, hold?, fallback?, ready? }` | — |

## Accessibility

- The popover is named by `title`, or by `description` when there's no title.
- Focus moves to the confirm button when it opens and back to the trigger when it closes.
- While `onConfirm` is pending, the popover stays open and the confirm button keeps focus.
